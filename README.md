# Klassrumsverktyget

Webbaserat klassrumsverktyg för mellanstadiet (åk 4) — morgonskärm, lektionsplanering,
trafikljusur för övergångar, elevlista med noteringar, och en översiktsvy. Ren frontend
(HTML5 + CSS + Vanilla JS, inget byggsteg), delad data mellan lärare via Firebase/Firestore
med offline-läge.

Byggs vy för vy. Se GitHub-issues för epiken och dess arbetsobjekt.
